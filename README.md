# DenshaDeGo_controller
[Picture](main/IMG_7512.JPG)
3d printed recreation of Densha de Go! train controller using limit switches or pogo pins. 
Please remind: This is not a perfect controller. I've made this controller as a test for myself. 
I've made it also because I want to experience Densha de Go! on train controller and not on gamepad. 
Controller have some issues that require some additional work but I don't know if I could solve them.
I think this may bring new peoples to this games as it's lowers a barrier of entry.
Feel free to modify this controller

This could not be possible without Train controller database: https://traincontrollerdb.marcriera.cat/index.html
